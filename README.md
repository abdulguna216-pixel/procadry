# ПРОКАДРЫ

Адаптивный одностраничный сайт по файлам `PROKADRY_1to1_SITE_PROMPT.md` и референсу из родительской папки. Семантический HTML, CSS и JavaScript без зависимостей и сборки. Все тексты, кнопки, форма и навигация — настоящие элементы страницы. Фотографии хранятся отдельно в `dist/assets`.

## Запуск

Нужен Node.js 18 или новее:

```sh
cd prokadry-site
npm run dev
```

Откройте http://127.0.0.1:4173. Другой порт: `PORT=8080 npm run dev`.

Проверка JavaScript: `npm run check`. Для любого статического хостинга достаточно содержимого `dist/`.

## Что работает

- Ссылки на секции, мобильное меню с Escape и закрытием после выбора.
- Выбор любого из трёх направлений в форме при клике на услугу.
- Пять FAQ с клавиатурным управлением и `aria-expanded`.
- Проверка имени, телефона и обязательного согласия, доступные сообщения ошибок.
- Отдельная страница конфиденциальности, статичная версия при `prefers-reduced-motion`.
- Локальные шрифты, отдельный мобильный фотокадр, WebP и lazy loading.

## Перед включением заявок

Обработчик CRM не предоставлен. После правильного заполнения форма честно показывает «Приём заявок ещё не подключён»; данные никуда не отправляются и не сохраняются сайтом. Подключение — в обработчике submit файла `dist/app.js` после валидации. Добавить реальный endpoint, обработку загрузки/ошибки/успеха и серверную проверку данных.

Потребуются реальные реквизиты компании, номер телефона, окончательная политика обработки персональных данных и подтверждение перечня услуг и процесса работы. Телефон-заглушка из референса и обещания сроков не опубликованы. Нейтральные ответы FAQ и описания процесса необходимо согласовать с компанией до публичного запуска.

## Отличия от эталона

Фотографии воссозданы встроенным imagegen по сценам референса и не являются оригинальной съёмкой. Шрифты — открытые Oswald 700 и Manrope (Google Fonts, OFL); оригинальная гарнитура не предоставлена. Начертания и кадрирование могут отличаться. Сохранены порядок секций, геометрия, палитра, лаймовая подложка и HTML-слои `/01` и `?`. Текст о географии, гарантии и фиктивный телефон заменены согласно промту.

## Файлы

- `dist/index.html`, `dist/styles.css`, `dist/app.js` — сайт.
- `dist/privacy.html` — сведения о конфиденциальности демонстрационной версии.
- `dist/assets/` — четыре отдельных фото, мобильный кадр и локальные шрифты.
- `qa/desktop-final.png`, `qa/mobile-390.png`, `qa/mobile-320.png` — скриншоты.
- `qa/comparison.png` — эталон слева, сайт справа, оба шириной 853 px.
- `qa/report.json` — отчёт проверок 1440/1280/1024/768/430/390/360/320 px.
- `ASSET_PROMPTS.md` — промты встроенного imagegen.

`qa/` не входит в публикацию. Для разработки не нужны ни API-ключи, ни сторонние пакеты.
